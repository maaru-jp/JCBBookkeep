# 刷卡紀錄（多銀行）

簡易、美觀的刷卡歷程紀錄工具，支援多張發卡銀行，方便對帳使用。

## 功能

- **多銀行分頁**：頂部可切換富邦、玉山等發卡銀行，各銀行帳單與統計獨立
- **各銀行結帳日**：每家可設定不同結帳日，新增時自動推算帳單月份
- **購物時**記錄：包裹單號、**多項商品（名稱＋數量＋日幣金額）**、積分／優惠券抵扣；日幣合計自動加總
- **收到帳單後**補上**台幣金額**（帳單明細上的 NT$）
- **快速對帳**：輸入帳單台幣金額 → 自動篩出相符紀錄 → 核對後「標記已對帳」
- **每月帳單**：依帳單月份歸戶（新增時預設為刷卡日所在月），可自由新增或移至其他月份
- 每筆可「移至帳單月份」下拉選單調整歸戶；各月份可「＋ 新增至此月份」
- 選填備註（分期、退貨、已對帳等）
- 搜尋、日期區間篩選
- 待對帳筆數 / 本月日幣・台幣合計 / 全部累計（依目前選取的銀行）
- **Google 試算表同步**：連結後，新增或修改紀錄會自動寫入（每家銀行一個分頁）

## 使用方式

1. **雙擊 `start-server.bat`**（或執行 `python -m http.server 8080`）
2. 瀏覽器開啟 **http://localhost:8080**（請勿直接雙擊 index.html）
3. 貼上 Apps Script 部署 URL，點「連結 Google」（詳見 [`google-apps-script/README.md`](google-apps-script/README.md)）
4. 頂部選擇要對帳的**發卡銀行**
5. 點「＋ 新增紀錄」填寫資料後儲存 → **自動寫入 Google 試算表**

| 包裹單號 | `TW123456789` |
| 商品名稱 | `無線耳機(¥5980)` |
| 商品日幣小計(¥) | `5980` |

## 新增第三家銀行

編輯 `js/app.js` 開頭的 `BANKS` 陣列，加入一筆即可，例如：

```js
const BANKS = [
  { id: "fubon", name: "富邦銀行", subtitle: "富邦 JCB 刷日幣 · 帳單對台幣", closingDay: 22 },
  { id: "esun", name: "玉山銀行", subtitle: "玉山 JCB 刷日幣 · 帳單對台幣", closingDay: 15 },
  { id: "other", name: "其他銀行", subtitle: "刷日幣 · 帳單對台幣", closingDay: null },
];
```

- `id`：英文小寫代碼（勿含冒號），作為資料識別用
- `name`：畫面上顯示的銀行名稱
- `subtitle`：標題下方的說明文字
- `closingDay`：每月結帳日（1–31）；設為 `null` 則依刷卡日曆法月份

### 結帳日規則

| 刷卡日 | 歸屬帳單月份（以富邦 22 日結帳為例） |
|--------|--------------------------------------|
| 4 月 10 日 | 2025-04（4 月帳單） |
| 4 月 25 日 | 2025-05（5 月帳單） |

區間為：**上月（結帳日+1）～本月結帳日**。各銀行可設定不同 `closingDay`，新增紀錄時會依所選銀行自動推算帳單月份；仍可用「移至帳單月份」手動調整。

## 資料儲存

- **瀏覽器 localStorage**：操作當下的暫存（離線仍可輸入，連結 Google 後會同步）
- **Google 試算表（主要）**：貼上 Apps Script 部署 URL 連結，每家銀行一個分頁，**新增或修改紀錄後自動寫入**

Google 連線需先部署 `google-apps-script/Code.gs`，詳見 [`google-apps-script/README.md`](google-apps-script/README.md)。

既有紀錄會自動歸入 **富邦銀行**（原 JCB 代碼）；各銀行的「已繳卡費」狀態以 `銀行代碼:帳單月份` 分開儲存。

同步後若出現 `NT$ 1,784,217,600,000` 這類天文數字，代表試算表分頁是舊版欄位造成整列錯位，
修正方式見 [`google-apps-script/README.md`](google-apps-script/README.md#同步後金額變成天文數字)。
